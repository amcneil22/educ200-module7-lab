🎓 Teacher debrief: What makes this gamification purposeful?

Objective: Identify equivalent fractions using visual models, recognize a non-equivalent relationship, and apply equivalence to a new problem.

Game mechanics: Three levels, mastery-based unlocking, feedback after errors, chances to retry, and completion celebration. The instructional feedback addresses students' thinking rather than rewarding speed.

Accessibility: Keyboard-operable controls, visible focus, written feedback accompanying audio, and no timer. Color is not the only signal of correctness. Audio can be muted.

Limitations: This demonstration uses selected-response questions; it does not independently measure students' ability to explain their reasoning. A teacher should add model-building and explanation tasks to assess the complete learning objective.

This prototype runs locally or from GitHub Pages. No login or student information required; no data is transmitted.
